# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/harrison-jennings/harrison-jennings/security/advisories/new),
with what you found and how to reproduce it.

## Scope

- This repository's script and GitHub Actions workflow.
- Out of scope: the sites and projects linked from the README (each has its own repository and security policy).
